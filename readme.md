# Сегментация питомцев (Oxford-IIIT Pet)

Решение соревнования Kaggle «CU CV Pet Segmentation Challenge 2026» на курсе «Компьютерное зрение» Центрального
университета. Нужно выделить питомца на фото: построить бинарную маску.

**Результат:** IoU 0.936 на валидации и 0.939 на отложенной части. На публичной части Kaggle 0.82659, первая версия
давала 0.80519. Подробнее в `report.md`.

## Решение

- **Данные.** Oxford-IIIT Pet без 14 масок «без питомца». Фото разделены на train (5863), eval (736) и holdout (736).
- **Модели.** U-Net с энкодерами ResNet34, ConvNeXt-Tiny и ConvNeXt-Small, а также DeepLabV3-ResNet50. Энкодеры
  стартуют с весов ImageNet.
- **Обучение.** BCE вместе с Dice, косинусный learning rate. Аугментации: повороты, отражения, цвет, перенос питомца на
  другой фон и уменьшение питомца.
- **Итог.** Ансамбль трёх моделей на 384 px: U-Net с ConvNeXt-Tiny, U-Net с ConvNeXt-Small и DeepLabV3, порог 0.45. Для
  Kaggle маска возвращается к исходному размеру и кодируется в RLE.

## Файлы

- `pet.ipynb` — основной ноутбук: данные, модели, обучение, маски и логи.
- `data.py` — подготовка данных, `run.py` — обучение одной модели, `mix.py` — ансамбль и ответ для Kaggle.
- `runs/*/log.csv` — логи обучения по эпохам, `mix.json` и `hold.json` — выбранный ансамбль и его метрики.
- `submission.csv` — ответ, отправленный на Kaggle.

Веса моделей (от 124 до 210 МБ каждая) в репозиторий не входят: GitHub не принимает файлы больше 100 МБ.

# Запуск

Нужен Python 3.12. 
```bash
python -m pip install -r req.txt
python data.py cu-cv-pet-segmentation-challenge.zip
python mix.py test --out reproduced.csv
```
Ноутбук показывает маски и логи. Чтобы построить CSV из сохранённых весов прямо в ноутбуке, выставьте `export = True` в последней ячейке.
Для нового обучения нужен gpu. В отдельной копии переименуйте папку `runs` и запусти `python run.py res320 train`. Для `convwide` сначала нужен запуск `conv384`.
